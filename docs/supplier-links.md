# Links de fornecedores

A Sprint 7 acrescenta caminhos para o usuário confirmar a estimativa diretamente com a companhia aérea. Os valores exibidos continuam simulados e não representam disponibilidade, reserva ou promessa comercial.

## Fontes oficiais

| Companhia | Consulta de passagens                                      | Atendimento                                                                  |
| --------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Azul      | [site oficial](https://www.voeazul.com.br/home/br/pt/home) | página oficial, com chat, Fale Conosco e telefones                           |
| LATAM     | [site oficial](https://www.latamairlines.com/br/pt)        | [Central de Ajuda](https://www.latamairlines.com/br/pt/central-ajuda)        |
| GOL       | [site oficial](https://www.voegol.com.br/)                 | [canais oficiais](https://www.voegol.com.br/atendimento/canais-oficiais-gol) |

Os links abrem em uma nova aba. O usuário deve repetir a pesquisa no fornecedor e confirmar preço final, taxas, bagagem, horários e disponibilidade.

## Limites desta etapa

- o mini app não recebe comissão nem intermedeia a compra;
- nenhuma informação de cartão ou passageiro é enviada às companhias;
- os links não carregam uma reserva nem garantem o preço demonstrado;
- a futura API de ofertas poderá substituir a estimativa, mantendo a mesma identificação de origem e atualização do preço.
